FileDB

FileDB is a lightweight, modern C++ library for importing, transforming, and querying structured data.

It provides a simple, extensible API for working with data from multiple file formats—including CSV, Excel, JSON, and more—while using SQLite as the underlying storage engine. Designed with portability and performance in mind, FileDB can be embedded into desktop applications, backend services, command-line tools, and WebAssembly applications.

Features
CSV data import
SQLite-backed storage
Modern C++20 API
Extensible importer architecture
Cross-platform design
WebAssembly-friendly architecture
